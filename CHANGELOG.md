# Changelog

All notable changes to **ADP: A Different Perspective** for IntelliJ Platform IDEs are listed here, newest first. The section of a version is shown as its "What's New" on the JetBrains Marketplace and in the IDE's plug-in manager.

## [Unreleased]

## [0.1.0] - 2026-11-24

### Added

- **Mind maps:** FreeMind mind maps (`.mm`) open as a map you can work in: add, rename, delete, move, drag and fold nodes from the keyboard or the context menu, with every change one step of Edit | Undo. The Structure tool window lists the node tree, and File | New | FreeMind Mind Map starts a new map.
- **draw.io diagrams:** uncompressed draw.io diagrams (`.drawio`) open with their shapes, connections, labels and swimlanes. Add shapes from the toolbox, connect, move, resize and delete them, and change their fill colours, line styles and labels. What the diagram does not show is kept as it is.
- **ADP Toolbox** and **ADP Properties** tool windows: drag new elements onto the canvas, and edit the properties of one or several selected elements at once. Double-click a text, or press F2, to edit it in place.
- **Settings | Tools | ADP** lists the tools and the files each one opens, and holds the canvas options.
- **Tool descriptions:** `.atd` files get live problem checking, completion, navigation, rename and formatting in every IDE with language server support.
